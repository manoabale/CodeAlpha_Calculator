# CodeAlpha_Calculator


This is a simple calculator built with HTML, CSS, and JavaScript for the CodeAlpha Internship.

## Features
- Basic arithmetic (+, −, ×, ÷)
- Scientific functions (√, %, ^)
- Keyboard support (Enter = calculate, Esc = clear)
- Dark mode toggle 🌙

## How to Run
Open `index.html` in your browser.
